# Απόδραση από τη Βιβλιοθήκη 3D

v2.0.0-rc.2 — Το μυστήριο του χαμένου χειρογράφου.

[Παίξτε](https://itzortzak.github.io/Library-Escape/) · [Εκδόσεις](https://github.com/itzortzak/Library-Escape/releases)

240 γρίφοι λογοτεχνίας Α΄ Λυκείου, δέκα θεματικές αίθουσες, 23 προαιρετικές δραστηριότητες, τρεις χαρακτήρες, ημερολόγιο και αποθήκευση προόδου. Προεπιλογή: τρεις γρίφοι ανά αίθουσα.

Εκτέλεση ελέγχων και παραγωγή: `python3 scripts/build.py`. Η εφαρμογή λειτουργεί αυτοτελώς με WebGL και εναλλακτική απόδοση Canvas. Αναλυτικές οδηγίες στο README.txt και όρια των ελέγχων στο VALIDATION.txt.

Η έκδοση είναι δοκιμαστική· δεν έχει αξιολογηθεί με μαθητές ή σε όλες τις συσκευές. Οι πηγές και οι παραπομπές βρίσκονται μέσα στην εφαρμογή.
