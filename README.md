# Library Escape — Απόδραση από τη Βιβλιοθήκη 3D

**Το Μυστήριο του Χαμένου Χειρογράφου** · Νεοελληνική Λογοτεχνία Α΄ Λυκείου.

Έκδοση εφαρμογής `v1.0.1`.

240 γρίφοι, 10 θεματικές αίθουσες, 24 ερωτήσεις ανά αίθουσα, 8 ανά βαθμίδα. Εξερεύνηση WebGL / ray casting, εργαστήριο αναγνωστών, λεξικό, πινακοθήκη, φίλτρα, αποθήκευση προόδου και εξαγωγή αποτελεσμάτων.

## Χρήση

[Releases](https://github.com/itzortzak/Library-Escape/releases) · [GitHub Pages](https://itzortzak.github.io/Library-Escape/) (ενεργοί μετά από επιτυχή εκτέλεση του workflow).

## Build

`python3 scripts/build.py` (απαιτεί Python 3 και Node.js). Τα 22 αριθμημένα τμήματα ανασυντίθενται σε `dist/index.html`, με έλεγχο SHA-256, σύνταξης JavaScript και δομής των 240 ερωτήσεων. Δημιουργείται και κατάλογος CSV. Το workflow εκτελεί build, prerelease και deployment. Αν το Pages δεν είναι ενεργοποιημένο, επιλέξτε Settings → Pages → Source → GitHub Actions.

## Περιορισμοί

Η συλλογή καλύπτει 26 εγγραφές έργων/ενοτήτων, όχι ολόκληρο το ανθολόγιο. Οι επιλογές εισαγωγής και συνέχισης αφαιρέθηκαν από το αρχικό μενού. Εκκρεμούν εξαντλητική φιλολογική επιμέλεια και δοκιμή WebGL σε πραγματική συσκευή. Οι παραπομπές δεν αποτελούν άδεια αναδημοσίευσης: τα δικαιώματα κειμένων, μεταφράσεων και εικόνων χρειάζονται ξεχωριστό έλεγχο. Δεν χορηγείται άδεια για υλικό τρίτων. Βλ. README.txt και CHANGELOG.md.
