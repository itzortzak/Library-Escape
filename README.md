# Library Escape — Απόδραση από τη Βιβλιοθήκη 3D

Εκπαιδευτικό παιχνίδι Νεοελληνικής Λογοτεχνίας Α΄ Λυκείου: Το Μυστήριο του Χαμένου Χειρογράφου.

Έκδοση 1.0.0 (υποψήφια τελική έκδοση). 240 γρίφοι, δέκα θεματικές αίθουσες και τρεις βαθμίδες δυσκολίας. Η ενσωματωμένη συλλογή καλύπτει 26 εγγραφές έργων/ενοτήτων, όχι ολόκληρο το ανθολόγιο. Η πλήρης φιλολογική επιμέλεια, η δοκιμή WebGL σε πραγματική συσκευή και ο έλεγχος δικαιωμάτων αναδημοσίευσης εκκρεμούν.

Η εφαρμογή βρίσκεται υπό διαδικασία αρχικής μεταφοράς.
