# Library Escape v3 — Τράπεζα ερωτήσεων υπό αναθεώρηση

Κατάσταση: **προσχέδιο, όχι παραγωγική έκδοση**.

Στις πέντε συλλογές `bank-draft-01.json`–`bank-draft-05.json` έχουν συνταχθεί 321 ερωτήσεις για 35 εγγραφές του σχολικού ανθολογίου. Από αυτές, 145 προορίζονται να αντικαταστήσουν 145 παλαιές ερωτήσεις 15 εγγραφών· 176 αφορούν 20 προηγουμένως ακάλυπτες εγγραφές. Απομένουν 95 παλαιές ερωτήσεις 11 εγγραφών και 69 εγγραφές χωρίς ερωτήσεις. Τα αριθμητικά δεδομένα προκύπτουν από την αντιστοίχιση με τον κατάλογο των 115 εγγραφών.

- `anthology-coverage.json`: αντιστοίχιση με το ανθολόγιο.
- `audit-v2.json`: έλεγχος της προηγούμενης τράπεζας.
- `draft-statistics.json`: τρέχουσα κάλυψη.
- `selector.mjs`: πειραματικός μηχανισμός τυχαιοποίησης.
- `selection-test-results.json`: αποτελέσματα 100 προσομοιώσεων.
- `validate-drafts.mjs`: αναπαραγώγιμος τεχνικός έλεγχος (Node.js).

Οι συλλογές 03–05 στηρίζονται στις αντίστοιχες ηλεκτρονικές σελίδες του επίσημου σχολικού βιβλίου. Οι ενδείξεις χωρίων είναι οδηγοί ανάγνωσης, όχι αναπαραγωγές του κειμένου. Οι αριθμοί έντυπων σελίδων δεν έχουν συμπληρωθεί μέχρι να ελεγχθούν. Οι ερωτήσεις δεν έχουν ακόμη αξιολογηθεί από ανεξάρτητο φιλόλογο ή σε πραγματική τάξη. Οι θεματικές ενδείξεις χρειάζονται τελικό έλεγχο σε επίπεδο ερώτησης και δεν συνεπάγονται ότι όλα τα κείμενα ανήκουν αυτομάτως στην εξεταστέα ύλη.

Εκτέλεση: `node question-bank-v3/validate-drafts.mjs`. Ο τεχνικός έλεγχος δεν υποκαθιστά τη φιλολογική επαλήθευση. Δεν έχουν τροποποιηθεί ο κύριος κλάδος, η παραγωγική τράπεζα, το build, η εφαρμογή ή η δημοσίευση GitHub Pages. Πριν από ενσωμάτωση απαιτούνται έλεγχος παραπομπών και δικαιωμάτων, προσαρμογή της απεικόνισης του κειμένου και των φίλτρων, αλλαγή των σταθερών 240 ερωτήσεων, δοκιμές πλήρους παρτίδας και αξιολόγηση της ποιότητας των λανθασμένων επιλογών. Οι ανοικτές ερμηνευτικές δραστηριότητες δεν αποτιμώνται αυτομάτως ως μία μοναδική σωστή απάντηση.
