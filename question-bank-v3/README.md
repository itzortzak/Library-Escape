# Library Escape v3 — Τράπεζα ερωτήσεων υπό αναθεώρηση

Κατάσταση: **προσχέδιο, όχι παραγωγική έκδοση**.

Οι οκτώ συλλογές `bank-draft-01.json`–`bank-draft-08.json` περιέχουν 463 ερωτήσεις για 50 από τις 115 εγγραφές του καταλόγου. 251 νέες διατυπώσεις προορίζονται να αντικαταστήσουν την παλαιά τράπεζα των 240 ερωτήσεων, καλύπτοντας και τις 26 παλαιές εγγραφές. 212 ερωτήσεις καλύπτουν 24 επιπλέον εγγραφές. Η αντικατάσταση γίνεται ανά έργο, όχι ως αντιστοίχιση μία προς μία· η επάρκεια ανά υποενότητα και η διατήρηση χρήσιμων παλαιών στόχων παραμένουν προς έλεγχο. Απομένουν 65 εγγραφές χωρίς ερωτήσεις.

- `anthology-coverage.json`: κατάλογος και αντιστοίχιση με το ανθολόγιο.
- `audit-v2.json`: τεχνικός έλεγχος της προηγούμενης τράπεζας.
- `draft-statistics.json`: αριθμητική κάλυψη.
- `selector.mjs`: πειραματικός μηχανισμός τυχαιοποίησης.
- `selection-test-results.json`: αποτελέσματα 100 προσομοιώσεων.
- `validate-drafts.mjs`: αναπαραγώγιμος τεχνικός έλεγχος (Node.js).

Οι συλλογές 06–08 ελέγχθηκαν με τις αντίστοιχες ηλεκτρονικές σελίδες του επίσημου σχολικού βιβλίου. Οι ενδείξεις χωρίων είναι οδηγοί ανάγνωσης και όχι αυτούσια αποσπάσματα. Ο οριστικός έλεγχος όλων των URL, της έντυπης σελιδαρίθμησης, της θεματικής σήμανσης και της ορθότητας των ερωτήσεων και παραπλανητικών επιλογών εκκρεμεί. Η κάλυψη ενός έργου σημαίνει ύπαρξη προσχεδίου, όχι εξαντλητική κάλυψη όλων των χωρίων του. Οι ενδείξεις εξεταστικών θεματικών δεν αποτελούν αυτόματα πιστοποίηση της εξεταστέας ύλης. Η έγκριση από φιλόλογο και η δοκιμή στην τάξη εκκρεμούν.

Εκτέλεση: `node question-bank-v3/validate-drafts.mjs`. Δεν έχουν τροποποιηθεί ο κύριος κλάδος, η παραγωγική τράπεζα, το build, η εφαρμογή ή η δημοσίευση GitHub Pages. Πριν από ενσωμάτωση απαιτούνται έλεγχος δικαιωμάτων, προσαρμογή εμφάνισης χωρίων, φίλτρων και καταμέτρησης ερωτήσεων, δοκιμές πλήρους παρτίδας και φιλολογική αξιολόγηση. Οι ανοικτές ερμηνευτικές δραστηριότητες χρειάζονται αξιολόγηση από εκπαιδευτικό.
