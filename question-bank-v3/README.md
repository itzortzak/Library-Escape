# Library Escape v3 — Τράπεζα ερωτήσεων υπό αναθεώρηση

Κατάσταση: **προσχέδιο, όχι παραγωγική έκδοση**.

Οι δεκαοκτώ συλλογές bank-draft-01.json–bank-draft-18.json περιέχουν 990 ερωτήσεις για όλες τις 115 εγγραφές του καταλόγου. Οι 251 νέες διατυπώσεις προορίζονται να αντικαταστήσουν την παλαιά τράπεζα των 240 ερωτήσεων σε επίπεδο των 26 παλαιών εγγραφών. Οι 739 ερωτήσεις καλύπτουν τις 89 επιπλέον εγγραφές. Η πρώτη κάλυψη του συνόλου των επτά γραμματολογικών ενοτήτων ολοκληρώθηκε.

- anthology-coverage.json: αντιστοίχιση με το ανθολόγιο.
- audit-v2.json: τεχνικός έλεγχος προηγούμενης τράπεζας.
- draft-statistics.json: αριθμητική κάλυψη.
- selector.mjs: πειραματικός μηχανισμός τυχαιοποίησης.
- selection-test-results.json: αποτελέσματα 100 προσομοιώσεων.
- validate-drafts.mjs: αναπαραγώγιμος τεχνικός έλεγχος (Node.js).

Οι συλλογές 16–18 καλύπτουν τις τελευταίες 16 εγγραφές, με 122 ερωτήσεις. Οι επίσημες ηλεκτρονικές σελίδες των 16 κειμένων αναγνώστηκαν κατά τη σύνταξη. Έλεγχος 990 μοναδικών εκφωνήσεων, 2.970 μοναδικών επιλογών και 100 προσομοιώσεων επιλογής (3.000 επιλογές) ολοκληρώθηκε χωρίς διπλότυπα ή δομικά σφάλματα. Η φιλολογική οριστικοποίηση και η ενσωμάτωση παραμένουν εκκρεμείς. Οι συλλογές 13–15 καλύπτουν τις εναπομείνασες εγγραφές της Ρομαντικής Σχολής και της ξένης λογοτεχνίας, τα έξι κείμενα του Παλαμά και τα Πρωτοβρόχια του Δροσίνη. Ερωτήσεις για έμφυλα στερεότυπα διακρίνουν τις απόψεις των προσώπων και της ποιητικής φωνής από τεκμηριωμένες πραγματολογικές κρίσεις. Στα μεταφρασμένα κείμενα η ανάλυση αφορά την ανθολογούμενη ελληνική μετάφραση. Οι συλλογές 11–12 στηρίζονται στην ανάγνωση των αντίστοιχων επίσημων ηλεκτρονικών χωρίων. Οι Στοχασμοί του Σολωμού αντιμετωπίζονται ως ποιητολογικές σημειώσεις χωριστά από τους στίχους των Ελεύθερων Πολιορκημένων. Τα δύο αποσπάσματα του Σκουζέ έχουν αυτοτελείς κωδικούς και παραπομπές σε διαφορετικά χωρία της ίδιας ηλεκτρονικής σελίδας. Για το Chronicon Maius διατηρείται η επισήμανση περί νεότερης απόδοσης στον Μακάριο Μελισσηνό.

Οι ενδείξεις χωρίων αποτελούν οδηγούς ανάγνωσης, όχι αυτούσια αποσπάσματα. Η κάλυψη μιας εγγραφής σημαίνει ύπαρξη προσχεδίου και όχι εξαντλητική κάλυψη όλων των ενοτήτων ή της εξεταστέας ύλης. Εκκρεμεί ο τελικός έλεγχος όλων των URL, της έντυπης σελιδαρίθμησης, της φιλολογικής ορθότητας, της δυσκολίας και της θεματικής σήμανσης σε επίπεδο ερώτησης. Η απουσία αυτούσιων διπλοτύπων δεν πιστοποιεί από μόνη της ότι αποκλείονται νοηματικές ομοιότητες ή προφανείς παραπλανητικές απαντήσεις.

Εκτέλεση: node question-bank-v3/validate-drafts.mjs. Δεν έχουν τροποποιηθεί ο κύριος κλάδος, η παραγωγική τράπεζα, το build, η εφαρμογή ή η δημοσίευση GitHub Pages. Εκκρεμούν έλεγχος δικαιωμάτων, ενσωμάτωση εμφάνισης χωρίων και φίλτρων, δοκιμές πραγματικής παρτίδας και αξιολόγηση από εκπαιδευτικό. Οι ανοικτές ερμηνευτικές δραστηριότητες χρειάζονται χωριστή αξιολόγηση.
